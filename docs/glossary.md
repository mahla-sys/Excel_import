# واژه‌نامه (Glossary)

| اصطلاح | معنی |
|---|---|
| **SchoolTenant** | یک مدرسه‌ی مستقل در این پرتال. معادل کپی School سیستم اصلی نیست؛ یک شناسه‌ی `external_code` پایدار برای تطبیق آینده دارد. |
| **PortalUser** | کاربر لاگین‌کننده در پرتال. یا `system_admin` است یا `school_operator`. دانش‌آموز/ولی/معلم در این سامانه لاگین نمی‌کنند. |
| **ImportBatch** | یک فایل Excel آپلودشده برای یک مدرسه در یک سال تحصیلی، همراه با تمام متادیتای پردازش و وضعیت. |
| **ImportRow** | یک ردیف خام از اکسل به‌همراه داده‌ی نرمال‌شده و خطاهای همان ردیف. `raw_data` هیچ‌وقت با نرمال‌سازی جایگزین نمی‌شود. |
| **StagedStudent** | پرونده‌ی موقت یک دانش‌آموز که از داده‌ی نرمال‌شده‌ی یک یا چند ردیف ساخته شده. هنوز در سیستم اصلی نوشته نشده. |
| **StagedGuardian** | اطلاعات ولی/سرپرست یک StagedStudent. در نسخه‌ی اول بین دانش‌آموزان Merge نمی‌شود. |
| **MappingProfile** | یک الگوی نگاشت ستون‌ها که توسط مسئول مدرسه ذخیره شده و در آپلودهای بعدی همان مدرسه قابل استفاده‌ی مجدد است. |
| **mapping_snapshot** | نسخه‌ی منجمد نگاشت در لحظه‌ی پردازش هر Batch، تا مراجعه‌ی بعدی مشخص باشد داده با چه تنظیماتی پردازش شده. |
| **Provenance** | منشأ هر فیلد: شماره‌ی Batch، ردیف، ستون، مقدار خام، مقدار نرمال، و در صورت اصلاح دستی ویرایش‌گر و دلیل. |
| **Canonical Data** | ساختار استاندارد داخلی سامانه (student, enrollment, contacts, guardians, admission, documents, extra_attributes) که همه‌ی اکسل‌ها به آن تبدیل می‌شوند. |
| **extra_attributes** | ستون‌هایی که به فیلد استاندارد نگاشت نشده‌اند اما مقدارشان حفظ شده است. هیچ ستونی بی‌صدا حذف نمی‌شود. |
| **Raw File** | فایل اصلی اکسل مدرسه که به‌صورت خصوصی با نام UUID نگه‌داری می‌شود و فقط با احراز هویت قابل دانلود است. |
| **Dry Run / Preview** | اجرای کل مسیر پردازش بدون اثر خارجی. چون این پرتال چیزی به سیستم اصلی نمی‌نویسد، برای پیش‌نمایش نگاشت/اعتبارسنجی استفاده می‌شود. |
| **school_operator** | مسئول یک مدرسه؛ فقط به داده‌ی همان مدرسه دسترسی دارد. |
| **system_admin** | مدیر فنی مالک سامانه؛ می‌تواند مدرسه و اپراتور بسازد و لاگ‌ها را ببیند. |
| **school_approver** | نقشی که در آینده افزوده می‌شود و تأیید نهایی Batch را از اپراتور جدا می‌کند (در MVP نیست). |
| **Issue / خطای ساختاریافته** | یک مشکل با `code`, `severity` (error/warning/info), `field`, `message`, `source_column`, `source_row`. |
